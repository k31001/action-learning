# 불변전략(Robust) 재검증 메모

> **목적**: 작업 1(불변전략 문서화) 진입 전, 기존 RS1~RS7의 "정말 모든 시나리오에서 가치를 만드는가"를 비판적으로 재검증하고, 추가/제거/통합 후보를 식별한다.
> **평가 기준**: 시나리오 A~E 5개 전부에서 ✅(긍정 가치)인가, 논리에 빈틈이 없는가, 다른 RS와 중복되지 않는가.
> **출처**: `analysis/scenarios/strategy.md` 매트릭스(L460), `analysis/scenarios/scenario-matrix.md`, `analysis/driving-forces/key-drivers.md`, `analysis/benchmark/cyclical-strategy-benchmark.md`

## 1. 기존 RS1~RS7 비판적 평가

| 현재 | 매트릭스 평가 (A/B/C/D/E) | 약한 시나리오 | 평가 | 권고 |
|---|---|---|---|---|
| **RS1** 옵션형 캐파 | ✅✅✅✅✅ | 없음 | 진정 Robust. "잘못된 타이밍의 고정 증설"은 모든 시나리오의 공통 적. 사이클 산업의 핵심 메커니즘 | **KEEP 그대로** |
| **RS2** 바벨 포트폴리오 + AI 효율화 | ✅✅✅✅⚠️ | E (HBM 위축 시 바벨 한쪽 붕괴) | ⚠ 수준이지 ❌ 아님. 바벨 자체는 architecture-agnostic하나, "AI 효율화 메커니즘"이 RS2에 묶여있는 게 부자연스러움 | **SPLIT** — AI 효율화는 별도 RS로 승격 |
| **RS3** 고객특화·전환비용 | ✅✅⚠️✅✅ | C (수요 감소로 co-dev 축소) | 락인 효과는 다운사이클에서 더 강하게 작동(전환비용이 인하 압박을 흡수). 매트릭스의 ⚠는 "신규 락인 작업이 줄어든다"는 의미일 뿐, 전략 가치 자체는 유효 | **KEEP** (논거 보강) |
| **RS4** 고객 포트폴리오 분산 | ✅✅✅✅✅ | 없음 | 진정 Robust. LTA/Take-or-Pay는 호황기에는 기회비용이지만 어떤 시나리오에서도 ❌ 아님 | **KEEP 그대로** |
| **RS5** 정책 리스크 지역 분산 | ✅⚠️✅✅⚠️ | B, E | **2개 시나리오에서 약함**. B(공존)에서는 분산 비용이 손해, E(기술 변화)에서는 우선순위 낮음. 본질적으로 **시나리오 A·C에 대한 헤지**이지 "어떤 시나리오에서도 가치"는 약함 | **DEMOTE** — Side Bet으로 강등 |
| **RS6** 재무 규율 + 초과이익 재투자 | ✅⚠️✅✅✅ | B (호황기 미세 제약) | "호황기 절제 = 다운사이클 자원"이 본질. ⚠는 의도된 trade-off지 결함 아님. 사이클 산업의 중심축 | **KEEP 그대로** |
| **RS7** NAND 공정 전환 주기 연장 | ✅✅✅✅✅ | 없음 | 진정 Robust. 공정 전환 비용은 모든 시나리오의 공통 적. 단, "NAND만"으로 한정한 게 다소 좁음 — DRAM 1c nm 우위(MB-3)도 동일 논리 | **EXPAND 검토** (DRAM 1c nm 흡수) |

## 2. 추가 후보 평가

### 후보 A. AI 엔지니어링 자동화 (현재 RS2 안에 묻혀 있음)

- **시나리오별 가치**:
  - A·C(디커플링): 인력 의존도를 낮추는 게 보안·인재 유출 리스크 완화에 기여 ✅
  - B(호황): R&D 속도 = 시장 점유율. AI 도구로 칩 설계·firmware 개발 사이클 단축 ✅
  - D(다운사이클): 인건비 절감 + 잉여 자원 전략 투입 ✅
  - E(패러다임): 신기술 R&D 가속에 직접 기여 (3D DRAM·PIM·CXL R&D 인력 확보) ✅
- **평가**: 5개 전부 ✅. RS2/RS3의 prerequisite로 묻혀있는 게 오히려 가치를 가린다. **독립 RS로 승격 권고.**
- **벤치마크 매핑**: TSMC가 "Fab Intelligence"로 수율을 산업 평균 대비 1세대 앞세운 사례, NVIDIA가 EDA 자동화로 칩 설계 주기를 단축한 사례

### 후보 B. 1c nm DRAM 공정 우위 (현재 MB-3, 매트릭스에서 이미 Robust 분류)

- **현재 매트릭스 평가**: ✅✅✅✅✅, 유형 칸에 "Robust"로 이미 표기됨
- **평가**: 매트릭스가 인정한 사실상의 Robust인데 라벨이 MB-3로 되어있는 inconsistency. **RS7과 통합해 "공정 리더십"으로 묶을지, 단독 RS로 승격할지 결정 필요.**
- **권고**: RS7과 통합. 둘 다 "공정 전환 비용을 사이클 전 구간에서 흡수"라는 동일 논리. 통합 시 RS7 제목을 "공정 리더십 통합 — 1c nm DRAM + NAND 주기 연장"으로 확대.

### 후보 C. 순현금 30조 버퍼 (현재 SC-2)

- **시나리오별 가치**: A·C는 생존, B는 기회 포착, D는 회복 가속, E는 피벗 자금 — 5개 전부 ✅
- **평가**: 진정 Robust 후보지만, **이미 RS6(재무 규율)에 흡수**되어 있다. 별도 RS 승격은 중복.
- **권고**: 분리하지 않음. RS6 안에 명문화 유지.

### 후보 D. 하이브리드 본딩 자체 IP / NVIDIA 생태계 통합 (CMX/SCADA/FDP)

- **평가**: 각각 RS7 트랙1, RS3 사례 안에 포함된 실행 메커니즘. 분리 시 과세분화.
- **권고**: 별도 RS로 승격하지 않음.

## 3. 최종 권고: **불변전략 7개 (구조 재편)**

### 변경 요약

| 변경 유형 | 항목 |
|---|---|
| **유지** | RS1, RS3, RS4, RS6 (4개) |
| **분할** | RS2 → 바벨(RS2) + AI 자동화(신설 RS7) |
| **확대** | RS7(NAND) → 공정 리더십(DRAM 1c nm + NAND 주기 연장) (RS6→RS6, 신설 RS6) |
| **강등** | RS5 정책 지역 분산 → Side Bet으로 (총 5개 사이드벳에 흡수) |
| **신설** | AI 엔지니어링 자동화 (구 RS2에서 분리) |

### 최종 7개 불변전략 (재번호)

| 신규 ID | 전략명 | 핵심 메커니즘 | 모든 시나리오 ✅ 근거 |
|---|---|---|---|
| **RS-1** | 옵션형 캐파 체계 | Fab Shell 선행 + 장비 단계 반입 + 롤링 캐파 리뷰 | "제때 켤 능력"이 "지을 능력"보다 가치 — 5개 시나리오 모두 |
| **RS-2** | 바벨 포트폴리오 | 고마진 + 저원가 양 끝, 가운데 축소 | 어떤 사이클에서도 양 끝 중 하나는 작동 |
| **RS-3** | 고객특화·전환비용 극대화 | NVIDIA CMX/SCADA/FDP 통합, Co-Validation, 베이스다이 커스텀 | 락인된 고객은 다운사이클에서도 이탈 안 함 |
| **RS-4** | 고객 포트폴리오 의도적 분산 | LTA + Take-or-Pay, 단일 고객 ≤25% | 협상력 비대칭 방지는 모든 시나리오에서 가치 |
| **RS-5** | 재무 규율 + 초과이익 재투자 | 재고일수 상한, FCF 기준, 다운사이클 capex 하한 | 호황기 절제 = 다운사이클 자원 (Nucor·ExxonMobil 모델) |
| **RS-6** | 공정 리더십 통합 | 1c nm DRAM 우위 + NAND 공정 주기 연장 + Hybrid bonding 자체 IP | 공정 전환 비용·라이선스 의존은 모든 시나리오 공통 적 |
| **RS-7** | AI 엔지니어링 자동화 | EDA·firmware·수율예측 AI 전사 도입 → 잉여 자원 전략 투입 | R&D 속도·원가·인력 효율은 5개 시나리오 모두에서 가치 |

### RS5(정책 지역 분산) 강등 처리

- 기존 RS5의 실행 방안(미국 팹·일본 R&D 허브·인도 OSAT 등)은 그대로 유지하되, **Side Bet A(시나리오 A 디커플링 헤지)** + **Side Bet C(시나리오 C 기술냉전 헤지)** 로 분산 매핑.
- `analysis/scenarios/strategy.md` 섹션 1·2에서 SA-2/SC-1과 통합되어 이미 일부 흡수돼 있음.

## 4. 대안: 최소 변경 (8개) 옵션

만약 재편 부담이 크다면 **최소 변경안**:

- 기존 RS1~RS7 그대로 유지 + AI 효율화만 RS8로 신설 (총 8개)
- RS5(정책 지역 분산)는 약점이 있지만 "정책 헤지 통합 전략"으로 재정의

이 경우 매트릭스 정합성은 약간 양보하되 기존 분석 자산을 최대한 보존.
