# 실사 플레이트 출처 — AI 생성 이미지

4장 모두 Figma generate_image(모델 gemini-3.1-flash-image)로 2026-10-11에 생성했다. 실존 인물·로고·문자는 없고, 특정 회사의 시설이나 제품을 묘사하지 않는 일반 장면이다. 영상 각주에 「이미지: AI 생성」을 표기한다.
원본 1376×768 PNG를 1920×1080으로 확대·크롭한 JPEG다(scripts/fetch-photos.sh).

| 파일 | 프롬프트 요지 | 사용 장면 |
|---|---|---|
| `wafer-frost.jpg` | 300mm 실리콘 웨이퍼 매크로, 가장자리부터 서리, 하이키 화이트 | 표지 콜드 오픈 |
| `cleanroom.jpg` | 빈 반도체 클린룸 복도, 하이키 화이트 | 2019 장 카드 |
| `hbm-package.jpg` | 범용 AI 가속기 패키지(중앙 다이 + HBM 스택), 무표기 | 봄 장면 후반 |
| `seedling.jpg` | 눈을 뚫고 나온 새싹 매크로, 하이키 | 교훈 |
