### v3.12 (1장 병렬 축: 다이 수·다이 고장률)

v3.12 피드백: "SSD에 들어가는 NAND 다이 수의 경향성도 봐야 한다. 다이 수가 늘수록 다이 고장으로 함께 버려야 할 다이가 늘어 SSD 고장률을 일정 수준으로 유지하려면 다이 고장률을 계속 낮춰야 하는 부담이 생겼고 기술적 한계에 봉착 — 칩 면적이 커질수록 수율을 올리기 어려운 것과 같은 원리. SSD 내부 RAID·여분 다이 교체 형태의 해법이 발전하는 방향이고, SSD 수준에서 해결하지 못하면 상위 계층의 도움이 필요할 수 있다. 첫 슬라이드에 포함." → 1장 하단에 **병렬 축 스트립**(`solution_ladder_slide.py` v1.4, 차트 높이 6.4→5.4in, 차트 글자 배율 1.15): 좌 라벨(병렬 축 · 다이 고장률 / 요구 FFR ≤ 3% 고정 · JESD218) + 미니 막대(SSD당 NAND 다이 수 환산 '12 128 → '18 144 → '21 256 → '23 512 → '25 1,024) + 칩 3(다이·단품: 다이 수 8배↑ → 다이 고장률 8배↓ 필요, SSD 고장률 ≈ N × 다이 고장률·칩 면적↔수율과 같은 원리·기술적 한계 → SSD 내부·현재 해법(연파랑): 다이 RAID·여분 다이·다이 은퇴 — Micron RAIN·삼성 Fail-in-Place(PM1733, 감량 운영)·패리티·예비 용량 오버헤드↑ → 상위 계층·SSD 단독 한계 시(점선): 감량 운영 수용·호스트 소거 부호 — OCP SMART XOR 복구 카운트·플랫폼 fail-in-place(MS Hyrax)·드라이브 간 소거 부호). 결론 1행 "요구(UBER·DWPD·FFR)는 고정, 단품 지표(RBER·P/E·다이 수)는 악화, 격차는 상위 계층이 보상해 왔습니다". 근거: 소스 §9 F41~F47(JESD218 FFR, S3700 분해·Kioxia LC9 32다이 스택, 수율 모델, Cai 패리티·Micron RAIN, 삼성 FIP, OCP SMART, MS Hyrax).

### v3.11 (1장 이관의 3단계 정정)
