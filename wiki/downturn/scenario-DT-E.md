# DT-E 「판 갈이」 — 와일드카드 (전환발)

**조건부 확률 8%** · [매트릭스](scenario-matrix.md) · 2×2 평면 밖 — 수요·공급 어느 축에도 속하지 않음

> 시장은 성장하는데 **우리 자산만** 다운턴에 들어간다. 다운턴 매뉴얼이 통째로 작동하지 않는 시나리오.

## 1. 내러티브

메모리 시장 전체는 계속 성장한다. 수요도 멀쩡하고 공급 과잉도 없다. 그런데 삼성의 특정 라인·제품군의 가치가 급락한다. **제품의 정의가 바뀌었기 때문이다.**

경로는 여러 갈래다. 3D DRAM·4F² VCT COP가 예상보다 빨리 상용 궤도에 오르면 2D 기반 DRAM 캐파의 원가 경쟁력이 무너진다. zHBM(3D 적층 커스텀 메모리)이 표준 HBM을 대체하기 시작하면 표준 HBM 라인의 가치가 떨어진다. CXL 메모리 패브릭이 서버 아키텍처를 바꾸면 서버 DRAM의 물량 구조가 재편된다.

공통점은 하나다. **감산도, 계약도, 가격 규율도 무의미하다.** 공급을 줄여도 그 제품의 수요가 돌아오지 않는다. 계약이 있어도 고객이 다음 세대로 넘어가면 갱신되지 않는다. 원가를 낮춰도 진부화된 제품의 원가일 뿐이다.

## 2. 이 시나리오의 정의적 특징

| 축 | 다른 네 시나리오 | **DT-E** |
|---|---|---|
| 총시장 | 축소 | **성장** |
| 노출 | 산업 전체 | **자산군별 비대칭** |
| 유효한 대응 | 감산·계약·매수·전환 | **개발 선행만** |
| 대비의 성격 | 완충재 축적 | **선택지 보유(실물옵션)** |
| 시간 | 분기 단위 | 년 단위 (그러나 되돌릴 수 없음) |

## 3. 세 개의 전환 경로

| 경로 | 무엇이 바뀌는가 | 위협받는 자산 | 근거 |
|---|---|---|---|
| **① 셀 구조 전환** — 3D DRAM·4F² VCT COP | 코어 면적 17.0% → 2.7%, 다이 +20%. 셀 아키텍처 자체가 바뀐다 | 2D 기반 DRAM 캐파·공정 IP | [logic-paradigm-shifts-3d-dram-2026-08.md](../../sources/articles/logic-paradigm-shifts-3d-dram-2026-08.md) |
| **② 패키지·커스텀 전환** — zHBM·커스텀 HBM | 표준 규격 대량 공급 → 고객별 설계 소량 다품종 | 표준 HBM 라인·범용 대응 체계 | [choi-jangseok-product-planning-interview-2026-07-29.md](../../sources/raw-notes/choi-jangseok-product-planning-interview-2026-07-29.md), [semianalysis-isscc-2026-2026-04-15.md](../../sources/articles/semianalysis-isscc-2026-2026-04-15.md) |
| **③ 계층 전환** — CXL 풀링·KV 캐시 오프로드 | 서버당 DRAM 탑재 구조가 재편, 메모리 계층이 재정의 | 서버 DRAM 물량 구조 | [emerging-tech.md](../concepts/emerging-tech.md) |

> **내부에서도 방향이 갈린다**: 커스텀 HBM에 대해 영업(이창수)은 **퇴조론**(속도전이라 표준화가 이긴다), 상품기획(최장석)은 **zHBM 커스텀 시대**로 본다. 이 불일치 자체가 DT-E의 불확실성이 실재한다는 증거이며, [SP-1 DF3](../driving-forces/key-drivers.md)의 리트머스와 같은 대상이다.

## 4. 왜 확률이 8%인가

- **하방**: 3D DRAM의 실질 위협은 2030년대 중반 — 2027~2030 시계에서는 개념 증명·초기 샘플 단계. 이 트랙의 시계 밖이다.
- **상방**: zHBM·CXL의 **부분** 발화는 이 시계 안에서 충분히 가능하다. 삼성 ISSCC 2026 4F² VCT COP DRAM 발표·zHBM FMS 2026 공개는 로드맵이 이미 움직이고 있음을 보여준다.
- 따라서 "전면 판 갈이"가 아니라 **"부분 판 갈이"**의 확률로 8%. SP-1 와일드카드 E(6%)보다 약간 높은 것은 시계가 다르고 부분 발화를 포함하기 때문이다.

## 5. 제품 축 노출

| 제품 | 노출 | 이유 |
|---|---|---|
| **2D DRAM 캐파 (선단)** | 🔴 경로① 직격 | 셀 구조 전환 시 공정 IP 가치 하락 |
| **표준 HBM** | 🔴 경로② 직격 | 커스텀 전환 시 대량 표준 공급 체계가 부적합 |
| **서버 DRAM** | 🟠 경로③ | 탑재 구조 재편 |
| **레거시 DRAM** | 🟢 무관 | 이미 하단 — 전환의 대상이 아님 |
| **NAND·SSD** | 🟡 낮음 | 오히려 KV 캐시 오프로드 수혜 |

### 6.2 대응 우선순위

1. **[DR-1 감별 프로토콜](response-playbook.md)** — DT-E는 오진 위험이 가장 크다. 특정 제품군만 빠지는 것을 "수요 둔화"로 읽으면 감산이라는 무효한 처방이 나온다. **총시장 성장률 vs 자사 해당 제품군 성장률의 괴리**가 판별 신호.
2. **[DR-6 조직 재편 — 경계 재획정](response-playbook.md)** — 제품 정의가 바뀌면 조직 배선도 바뀌어야 한다. 2019년 HBM팀 해체가 반대 방향의 교훈이다.
3. **[DR-4 기술 자산 취득](response-playbook.md)** — **◎.** 신기술 IP·팀 매수 창이 열린다. 대상은 캐파가 아니라 사람과 특허.
4. **감산·계약 방어는 발동하지 않는다** — 무효한 처방.

### 6.3 이 시나리오에서 가장 흔한 실수

| 실수 | 왜 발생하는가 | 차단 |
|---|---|---|
| **전환발을 수요발로 오독** | 매출이 빠지는 모습이 같다 | 총시장 성장률과의 괴리를 감별 1순위 지표로 |
| **별동대 재후순위화** | 주력이 어려울 때 니치를 자른다 | **HBM 40%→17%를 만든 바로 그 배분 논리.** 별동대를 주력 배분 논리에서 면제(SD-1) |
| **"우리도 하고 있다"로 안심** | 로드맵에 항목은 있다 | 항목 존재가 아니라 **진척 마일스톤**을 지표로 |
| **표준 vs 커스텀 논쟁의 미결 방치** | 내부 관점이 갈려 있다 | 리트머스 지표(`custom_hbm_revenue_share`)로 논쟁을 데이터에 위임 |
