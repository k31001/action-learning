# Impact × Uncertainty 매트릭스

## 평가 기준

### Impact (영향력): 삼성전자 메모리사업부의 2030~2035년 전략적 포지션에 미치는 영향 크기
| 점수 | 기준 |
|------|------|
| 5 | 사업 존폐·시장 리더십을 결정하는 근본적 영향 (매출·점유율 30%+ 변화 가능) |
| 4 | 전략 방향 전환이 필요한 중대한 영향 (매출·점유율 10~30% 변화 가능) |
| 3 | 사업 성과에 유의미한 영향 (일부 제품군이나 특정 시장에서 점유율 변화) |
| 2 | 제한적 영향 (비용·운영 효율에 영향, 전략 방향 변경 불필요) |
| 1 | 미미한 영향 (모니터링 수준, 단기 적응으로 해소 가능) |

### Uncertainty (불확실성): 2030~2035년 시점에서 해당 요인의 방향·크기 예측 가능성
| 점수 | 기준 |
|------|------|
| 5 | 전혀 예측 불가능. 복수의 극단적 결과 모두 가능 |
| 4 | 방향은 추정 가능하나 크기·시점이 불확실 |
| 3 | 현재 트렌드가 지속될 가능성이 높으나 반전 시나리오 존재 |
| 2 | 대체로 예측 가능하나 소폭의 변동 여지 있음 |
| 1 | 거의 확정적. 반전 가능성 매우 낮음 |

| 코드 | 요인명 | I×U | 핵심 내용 |

## 입력·출력 연결

본 매트릭스는 STEEP 브레인스토밍 요인을 영향력×불확실성으로 점수화하는 단계다. (Shell 시나리오 플래닝 파이프라인)

- **입력 — STEEP 5개 카테고리**: [Social](../steep/social.md) · [Technology](../steep/technology.md) · [Environment](../steep/environment.md) · [Economy](../steep/economy.md) · [Political](../steep/political.md)
- **출력 — Driving Force 선정**: 상위 6개 후보 → [핵심 Driving Forces](key-drivers.md) 에서 DF1·DF2 주축 + DF3 보조 축으로 최종 선별
- **다운스트림**: 선정된 DF → [시나리오 매트릭스](../scenarios/scenario-matrix.md) 2×2 구성
