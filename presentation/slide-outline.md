## 슬라이드 5: 왜 지금 시나리오 플래닝인가?

**레이아웃**: 텍스트 + 2×2 미니 매트릭스 조합  
**목적**: 단선적 예측이 아닌 시나리오 플래닝이 필요한 이유를 논리적으로 설명

### 콘텐츠
**헤드라인 메시지**: 두 개의 독립적 불확실성이 교차하는 곳에서 단일 예측은 위험하다

```
[상단 — 불확실성의 본질]
미래는 하나가 아니라 최소 4가지다.

불확실성 1: AI 수요의 구조적 지속성
  → AI CapEx 슈퍼사이클 지속? vs. ROI 실망으로 2027~2028년 급위축?
  → 기술·경제 내적 논리로 결정 (예측 불가)

불확실성 2: 미중 기술 디커플링 강도
  → 전면적 기술 분리? vs. 선택적 허용으로 관리된 공존?
  → 외교·안보 논리로 결정 (예측 불가)

[하단 — 방법론 소개]
Shell 시나리오 플래닝
  ① STEEP 50개 요인 도출 → ② I×U 매트릭스 분석
  → ③ 2개 Driving Force 선정 → ④ 5개 시나리오 구성
  → ⑤ 시나리오별 전략 설계 → ⑥ EWI 대시보드

[우측 — 2×2 미니 프리뷰]
        디커플링
          │ A    
          │      B ⭐
──────────┼──────────
 AI붕괴   │ C    D
          │
        공존
```

### 시각자료
- 유형: 좌측 불확실성 2개 블록 + 우측 상단 플로우 다이어그램 + 우측 하단 2×2 미니 매트릭스
- 플로우: ①→②→③→④→⑤→⑥ 번호 아이콘 + 화살표
- 미니 매트릭스: 시나리오 B에만 오렌지 별표 ⭐ + 강조 배경
- 핵심 강조: "두 개의 독립적 불확실성" → 언더라인 오렌지

### 스피커 노트 (발표자 말할 내용 요약)
"수요 예측만으로는 전략을 세울 수 없는 이유가 있습니다. AI 수요가 지속될지, 그리고 미중 갈등이 심화될지—이 두 변수는 독립적으로 작동합니다. 하나가 다른 하나의 원인이 아닙니다. 따라서 조합하면 최소 4가지 시나리오가 나옵니다. 우리는 Shell 방법론을 적용해 50개 환경 요인 분석부터 시작해 5개 시나리오와 전략을 도출했습니다."

### 디자인 지침
- 색상 팔레트: 삼성 블루 플로우 화살표, 오렌지 미니 매트릭스 강조
- 폰트 크기: 불확실성 제목 20pt Bold, 설명 14pt
- 특이사항: 방법론 플로우에 번호 원형 배지 삽입 (①~⑥)

## 슬라이드 9: STEEP 분석 개요

**레이아웃**: 2단 — 좌측 방법론 설명, 우측 거품 차트  
**목적**: 50개 요인 분석의 엄밀성과 체계성을 보여주고, 핵심 불확실성 집중 영역을 시각화

### 콘텐츠

```

  S — Social    10개 요인
  T — Technology  10개 요인
  Ec — Economy  10개 요인
  En — Environment 10개 요인
  P — Political  10개 요인
  ────────────────
  합계: 50개 요인

평가 기준:
  Impact(영향력): 1~5점
  Uncertainty(불확실성): 1~5점
  I×U 합산점수 = 우선순위

분류 결과:
  ● 핵심 불확실성 (I≥4, U≥4): 20개
  ◆ 기정사실 (I≥3, U≤3): 8개
  ○ 주변부 요인: 22개

[우측 — 산점도 / 거품 차트]
X축: Uncertainty 1→5
Y축: Impact 1→5
우상단 박스 강조: "핵심 불확실성 영역"
  T3(3D DRAM) I×U=25 ● 대형
  Ec6(AI 버블) I×U=25 ● 대형
  P1(수출통제) I×U=25 ● 대형
  P8(대만 해협) I×U=25 ● 대형
```

### 시각자료
- 유형: 우측 2×2 산점도 — X축 Uncertainty, Y축 Impact
- 거품 크기 = I×U 점수, 색상 = STEEP 분류 (S:노랑, T:블루, Ec:오렌지, En:그린, P:레드)
- 우상단 I≥4·U≥4 영역에 점선 박스 + "핵심 불확실성" 레이블
- I×U=25인 4개 요인: 대형 거품 + 흰 테두리 강조
