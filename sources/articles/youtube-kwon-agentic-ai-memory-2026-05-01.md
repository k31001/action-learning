## 핵심 사실·주장

### 1. 추론 패러다임 전환 (학습 → 추론 100배)

- Jensen Huang GTC 발언: "추론 연산이 학습 대비 10~100배 커질 것"
- 추론 단계 = ① Prefill(사용자 입력 처리) + ② Decode(맥락 발견·정보 생성)
- **Decode가 메모리 병목의 핵심** — 더 많은 정보 찾고 맥락 발견 필요

### 2. HBM3E도 토큰 한계 도달

- 현재 가장 앞선 5세대 HBM(HBM3E)도 **수십만 개 토큰만 되어도 차고 넘침**
- **병목이 GPU가 아니라 메모리로 이동**
- HBM만으로는 추론 수요를 다 커버 불가

### 3. HBM-DRAM 사이 '징검다리' 메모리 (새 시장)

- **메모리 수직 계열화 구조**:
  - 빠르지만 비싼 HBM
  - 느리지만 싼 범용 DRAM
  - **그 사이 징검다리 메모리** = CXL · GDDR · KV 캐시용 플래시
- KV 캐시 오프로드 = NVIDIA CMX 같은 솔루션
- 신규 시장 형성 — 메모리사가 잘 안 해본 영역

### 4. 클로드 코드 사례 — AI 에이전트 메모리 폭식 증명

- 권 교수 직접 경험: 10만 줄 코드 → 한 달 작업 → **1일 만에 완료, 속도 20배**
- 권 교수 월 수백만 원 클로드 사용 — "돈값을 한다"
- 시사: 토큰 양 폭증 → 메모리 수요 폭증

### 5. 애플 온디바이스 AI 진입 시 거대 폭풍

- 애플이 에너지 효율 무기로 온디바이스 AI 시장 본격 등판 가능성
- **스마트폰 폼팩터에 최적화된 새 메모리 규격 등장 가능**
- 기존 시장 압도하는 대격변

### 6. 일본 폼팩터 실패 교훈

- 일본 반도체가 망한 이유 중 하나 = **폼팩터 전환기를 놓침**
- 한국도 동일 위험 — 슈퍼사이클 정점에서 폼팩터 전환을 놓치면 동일 결과

### 7. HBM4E 격전지: 삼성 IDM vs SK + TSMC 연합

- **삼성**: IDM(Integrated Device Manufacturer) 모델 — 종합반도체 생태계 자체 보유
- **SK + TSMC**: 메모리 + 로직 파운드리 연합군 (적군이 아닌 협력자 관점)
- HBM4E 세대에서 두 모델의 격돌
- 권 교수의 이전(2026-04-11) "TSMC 인질 위기" 표현과 미묘한 뉘앙스 변화 — 연합으로 봄

### 8. 수십조 이익 이면의 천문학적 CAPEX

- 메모리 수십조 이익이 나도 장비 교체·R&D에 곧바로 쏟아부어야 하는 산업 생리
- 성과급 논란 뒤 숨은 CAPEX 부담
